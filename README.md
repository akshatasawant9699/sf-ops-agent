# sf-ops-agent

**What:** An eval-tested Salesforce ops agent, built as an MCP server that lets an LLM agent look up accounts, summarise open cases and create follow-up tasks in a Salesforce Developer Edition org.
**Why:** To show production-grade agent engineering in public: a golden dataset, an eval harness with code checks and an LLM-as-judge, tracing, and evals running in CI on every push.
